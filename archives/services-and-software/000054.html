Which open-source search engine do you use to index your web site?

Posted : May 7, 2004 at 5:33 pm [America/Los_Angeles]


Mike has an interesting post today on a Lucene-driven search engine application called “Nutch”. Needless to say, Nutch is the latest entry in a rather crowded field of search engine applications for web sites. Personally I have used ht://Dig in the past and it has served me well.

Here are some of the things I personally look for in such search engines, besides the usual quality indexing and searching capabilities:

  1. The search engine should have the ability to index PDF, MS Word, MS Excel besides just HTML or raw text
  2. The search engine UI should be highly customizable. In other words, it should allow me to configure the output of the search results

So, what search engines (besides the one that comes built-in with your Blogger) do people use? If you had to use one today, which one will it be? Anyone have any experience with Nutch.

Google Desktop: Indexing the bits and bytes of your personal life…

Posted : March 7, 2005 at 9:38 am [America/Los_Angeles]

Superlative stuff. Features I luv in this release:

  • Supports Thunderbird/Netscape Mail and Firefox/Mozilla.
  • Plug-in architecture. If you don’t find a file type supported by Google Desktop, write a plug-in or wait for someone to do it for you. There is already support for Trillian Pro Chat conversations. Nice!
  • Search directly from your desktop with the deskbar!

I use Thunderbird as my Email client and have had problems in searching my emails with the Copernic desktop search tool. Since I use IMAP protocol to access my emails, I am guessing that the reason Copernic failed to index my emails in Thunderbird was because there were no emails on my desktop to index! It will be interesting to see how good (or bad) Google Desktop does.

If it’s not clear by now, let me state the obvious:

I think Desktop search tool is a great step forward in harnessing the rapidly burgeoning content on a user’s desktop, especially since it’s no longer uncommon to have more than 100GB diskspace on a typical home computer! It is no secret that everyday more and more aspect of our lives are getting digitized be it books, photos, music, movies, identity, health records, financial records etc. etc. We need a killer app to get to them quickly. This modular and extensible release of Google desktop is a great step in that direction.

Update 1::

Well, here’s what Google Desktop had to say about indexing Thunderbird emails: “Thunderbird email is indexed only when the application is open.” Cool. Looks like I really did not need to enable offline access for my IMAP folders in order to have them indexed afterall.

Update 2::

Thunderbird emails got indexed and worked like a charm. However, I think you will have to download the messages from your IMAP folders (using offline access capability) for the search to work. Still working on having it confirmed…

- Anand

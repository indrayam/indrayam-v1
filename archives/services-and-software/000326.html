Skype: Now supporting Linux platform as well

Posted : June 28, 2004 at 10:46 am [America/Los_Angeles]

I have not looked at their releases for some time now. Frankly, I was impressed to read about some of the features that they’ve added in their latest release. Here’s a quick look:

  • feature: Dialpad
  • feature: Add a Friend - Possible to add PSTN numbers to FriendsList
  • feature: Possible to start call to PSTN number directly from conext sensitive menu if user has set his/her number in profile
  • feature: Avatar browser
  • feature: Added possibility to search users by age range
  • feature: Italian and Russian languages added to installer

Skype Release Notes

Cool! Personally, I think it’s high time they added support for Mac OS X as well.
